Acknowledgments

Thank you

Tau Ceti runs on inference its contributors and funders bring, compute from several providers, and a great deal of open-source software. Its outputs are free, as in both speech and beer, under the Apache licence.

Incubation

Lean FRO

The Lean Focused Research Organization, which builds and maintains Lean.

Mathlib Initiative

Which supports Mathlib, the library Tau Ceti is built on and defers to.

Funders

Anthropic

A grant of inference (API credits) from Anthropic’s AI for Science program, which runs standard workers on every published roadmap and roadmap “speed runs” at workshops.

Lean FRO

Covers Tau Ceti’s CI costs.

Most inference comes from contributors, who run workers on their own subscriptions: see People.

Compute

Every pull request is built in a sandbox on one of several fleets: GitHub-hosted runners (free for public repositories), Namespace runners, and the servers eastanglia, provided by Chris Birkbeck at the University of East Anglia, and leanfro, provided by the Lean FRO. The same servers run the agents the Anthropic grant pays for. The health page shows how the fleets are used.

Support Tau Ceti

Tau Ceti runs on a shoestring. Inference and compute for CI are both welcome, and a wider team is preparing a proposal for a sustainable funding model and for scaling up. If you would like to support the project, get in touch on the Lean Zulip. To contribute inference yourself, run a worker.

Built on

Lean 4

The language and kernel that check every proof.

Mathlib

The community library underneath everything, and its linters.

Verso and doc-gen4

The tools behind taucetiproject.org and its API documentation.

Intentions

The shared registry that keeps Tau Ceti’s agents clear of work others have claimed.

bors-ng

The merge bot that batches approved pull requests onto main.

bubble

The sandbox that isolates agent rounds from their hosts.
