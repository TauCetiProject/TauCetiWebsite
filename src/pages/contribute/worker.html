Run a worker

{{contribute_nav}}

The worker, tauceti, runs as your GitHub account. Each round it does the first job that applies, in a fixed order: upkeep of its own pull requests and of the library first, then reviews of others’ pull requests, then new roadmap work (the current order). It does that one job with your agent, and stops. You author through your own fork, which it creates for you, so you need no write access to Tau Ceti.

  1. Install the prerequisites

    You need gh, git, uv, jq, elan for Lean, and the command-line agent for your subscription: Claude Code or Codex. command -v gh git uv jq elan claude codex shows which you already have.

    With Homebrew:

    brew install gh git jq uv
curl -sS https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh | sh -s -- -y
curl -fsSL https://claude.ai/install.sh | bash   # Claude Code, for a Claude subscription
brew install --cask codex                        # Codex, for a ChatGPT subscription
    sudo apt update && sudo apt install -y git jq curl
curl -LsSf https://astral.sh/uv/install.sh | sh
curl -sS https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh | sh -s -- -y
curl -fsSL https://claude.ai/install.sh | bash   # Claude Code, for a Claude subscription
npm install -g @openai/codex                     # Codex, for a ChatGPT subscription (needs Node.js)
. ~/.profile                                     # put the new tools on PATH

    For gh, add GitHub’s package repository as in its Linux instructions; the distribution’s own gh is often too old.

    The worker runs in Linux, which Windows provides through WSL. In PowerShell, run as administrator:

    wsl --install

    This installs Ubuntu. Restart when asked, open Ubuntu from the Start menu and choose a Linux user name and password. Everything from here on, including the steps below, runs in that Ubuntu terminal:

    sudo apt update && sudo apt install -y git jq curl
curl -LsSf https://astral.sh/uv/install.sh | sh
curl -sS https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh | sh -s -- -y
curl -fsSL https://claude.ai/install.sh | bash   # Claude Code, for a Claude subscription
npm install -g @openai/codex                     # Codex, for a ChatGPT subscription (needs Node.js)
. ~/.profile                                     # put the new tools on PATH

    Install gh from GitHub’s package repository as in its Linux instructions. Keep your work in the Linux home directory rather than under the Windows drive (/mnt/c): Lean builds are much slower across that boundary. The logins below print a link or a code to open in your Windows browser.

    You need only one of Claude Code and Codex.

    Then log in to GitHub and to the agent you want to use:

    gh auth login          # the worker acts as this account
claude auth login      # if you have a Claude subscription
codex login            # if you have a ChatGPT/Codex subscription

    The worker uses whichever agent is logged in and has quota. Pass --agent claude or --agent codex if you prefer one. Over ssh, codex login --device-auth prints a URL and code instead of opening a browser.

  2. Install the worker and check your setup

    uv tool install git+https://github.com/TauCetiProject/TauCetiWorker
tauceti doctor

    tauceti doctor prints a row for each prerequisite and says what is missing. The bubble, incus, pi and kiro rows can stay missing unless you want the sandbox or another agent.

  3. Look before you act

    tauceti status           # read-only: available work and your quota

    Which job a round takes is decided when it runs, since the queue moves and other workers claim jobs.

  4. Do one round, then loop

    tauceti work             # ONE unit of work, then exit
tauceti work --loop      # keep picking the most useful job until Ctrl-C

    Run a single round first so you see one end to end. Pin a worker to one kind of work with --only review, --only fix or --only roadmap. The worker paces itself against your subscription’s session and weekly limits; see pacing.

By default agents run with unrestricted access to your machine. For isolation, run rounds in the --bubble sandbox (Linux with Incus).
